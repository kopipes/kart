# Rencana implementasi

1. **Fondasi ruang:** server HTTP/WebSocket tanpa dependensi, kode ruang, host, nama, batas delapan pemain, mode sendiri, dan rematch.
2. **Balapan otoritatif:** lintasan bersama, fisika kart, input tombol, checkpoint berurutan, tiga lap, waktu finis, batas waktu, dan klasemen.
3. **Item dan interaksi:** kotak item dengan respawn, slot satu item, boost, shield, dan jebakan yang dihitung server.
4. **Pengalaman bermain:** identitas visual orisinal, Canvas responsif, kontrol keyboard dan sentuh, HUD, lobi, hitung mundur, mode menonton, dan hasil akhir.
5. **Verifikasi:** tes aturan inti dan protokol ruang, uji alur pada browser, serta dokumentasi menjalankan proyek.

Proyek ini berdiri sendiri. Birdy hanya dijadikan referensi pola sesi; tidak ada file Birdy yang diubah atau detail mesin pribadi yang disalin.
